# Guess the Number Game 🎯

A simple Python console game where the user tries to guess a secret number.

This project is made as a beginner-friendly practice to understand Python loops, conditions, and user input.

---

## 🕹️ How the Game Works
- The program stores a secret number
- The user guesses the number
- The program tells whether the guess is:
  - TOO HIGH
  - TOO LOW
- The game continues until the correct number is guessed
- The total number of attempts is displayed at the end

---

## ▶️ How to Run the Game
Make sure Python is installed on your system.

Run the following command in terminal or command prompt:

```bash
python guess_game.py
